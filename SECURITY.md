# Security

agent-shield is a security tool, so bypasses matter.

## Reporting a bypass or vulnerability

Please **don't open a public issue**. Report it privately on GitHub:
**Security tab → "Report a vulnerability"** in this repository.

Include what you tried, what you expected the shield to do, and what actually happened (a config and a short script are ideal).
You'll get a reply within a few days. Fixes are released as patch versions and noted in the [CHANGELOG](CHANGELOG.md).

## Supported versions

Only the latest release gets security fixes. Please upgrade before reporting.

## Known limits

Some gaps are known and documented rather than bugs; see the [Limits](https://priyanshu-34.github.io/agent-shield/limits) page.
